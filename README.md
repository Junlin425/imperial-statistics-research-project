# Stochastic-volatility ABC project

This folder contains the code and saved outputs used in the MSc report. The
implementation compares Manual ABC, learned-summary Auto ABC, one-dimensional
Wasserstein ABC and ABC-SMC for a Gaussian stochastic-volatility model.

The repository includes the Python source code, tests, input returns, saved
posterior and diagnostic tables, NumPy result files and the separate figures
used in the report. Large fitted random-forest `.pkl` files are not stored in
Git because they can be rebuilt with scripts `10` and `28`.

## Setup

The saved results were produced with Python 3.12.10. From this folder, install
the recorded packages with:

```powershell
python -m pip install -r requirements.txt
```

Run scripts from the `scripts` folder. All paths are based on the script
location, so outputs do not depend on the current working directory.

```powershell
cd scripts
python 10_train_auto_summary_sv.py
```

## Main execution order

The numbered files follow the order of the analysis:

1. `01` to `04`: download prices, create returns and inspect volatility.
2. `05` to `13`: build the simulator and run the three rejection methods on
   S&P 500 returns.
3. `14` to `19`: generate the stored synthetic series and measure parameter
   recovery.
4. `20` to `23`: posterior predictive checks and convergence checks.
5. `24` to `27`: ABC-SMC and separate thesis figures.
6. `28`: learned-summary feature ablation.
7. `29`: temporal-order sensitivity by block permutation.
8. `30`: financially interpretable parameter transformations.
9. `31`: repeated synthetic volatility regimes.
10. `32`: simulator-cost comparison.
11. `33`: refresh audit tables and repeated-study figures from saved results.

Scripts `31` and `32` take the longest because they repeat ABC-SMC and large
simulation banks. The repository already contains their CSV, JSON, NumPy and
figure outputs. Script `33` does not rerun those experiments.

If a script needs `rf_sv_summary.pkl`, run `10_train_auto_summary_sv.py`
first. The feature-ablation models are regenerated by
`28_learned_summary_ablation.py`.

## Important design details

- All methods use the same prior bounds and SV simulator.
- The three rejection methods share a parameter bank in formal comparisons.
- Invalid near-degenerate simulations receive the same treatment in every
  rejection method. Their rates are reported in
  `scripts/simulation_validity_summary.csv`.
- Auto ABC scales its three predictions using held-out validation predictions.
  The validation labels are used for model scores, not for posterior selection.
- The repeated regime study uses five common-random-number seed blocks across
  six regimes. Block bootstrap comparisons are stored in
  `scripts/repeated_regime_block_comparisons.csv`.
- Auto ABC training calls and Manual-summary scale-bank calls are reported
  separately from inference calls.

## Tests

Run the test suite from `scripts`:

```powershell
python -m unittest discover -s tests -v
```

Small test configurations are used so the tests finish without rerunning the
full experiments.
