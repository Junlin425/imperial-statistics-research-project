# Result provenance

This file links the report evidence to the code and saved outputs.

| Report evidence | Main script | Saved source |
|---|---|---|
| Learned-summary validation | `10_train_auto_summary_sv.py` | `auto_summary_validation_metrics.csv`, `auto_summary_training_metadata.json`; the large `rf_sv_summary.pkl` model is regenerated by the script |
| Synthetic rejection posteriors | `15_manual_abc_synthetic.py` to `18_compare_synthetic_posteriors.py` | `abc_*_synthetic_sv.npy`, method metadata JSON files, `synthetic_error_table.csv` |
| Real-data posteriors | `08_abc_manual_sv.py`, `11_abc_auto_sv.py`, `12_abc_wasserstein_sv.py`, `13_compare_posteriors.py` | `abc_*_sv.npy`, method metadata JSON files, `real_data_results_table.csv` |
| ABC-SMC comparison | `24_abc_smc_synthetic.py` to `26_compare_abc_smc.py` | `abc_smc_*`, `abc_smc_method_comparison.csv` |
| Posterior predictive checks | `20_posterior_predictive_check.py`, `23_posterior_predictive_pvalue.py` | `posterior_predictive_*.csv`, `posterior_predictive_draws.npz` |
| Manual ABC convergence | `21_convergence_study.py`, `22_plot_convergence.py` | `convergence_study_raw.csv`, `convergence_study.csv` |
| Learned-summary ablation | `28_learned_summary_ablation.py` | `learned_summary_ablation_*.csv`, `learned_summary_ablation_metadata.json` |
| Temporal-order sensitivity | `29_temporal_order_sensitivity.py` | `temporal_order_sensitivity_raw.csv`, `temporal_order_sensitivity_summary.csv` |
| Financial transformations | `30_financial_derived_quantities.py` | `financial_derived_quantities_*.csv` |
| Repeated regimes | `31_repeated_synthetic_regime_study.py` | `repeated_regime_*.csv`, `repeated_regime_posteriors.npz` |
| Simulator-cost comparison | `32_fixed_budget_study.py` | `fixed_budget_*.csv`, `fixed_budget_metadata.json` |
| Validity and block audit | `33_refresh_reporting_outputs.py` | `simulation_validity_summary.csv`, `repeated_regime_block_comparisons.csv` |
| Scaled single-series errors | `34_supervisor_revision_diagnostics.py` | `synthetic_scaled_error_table.csv` |
| Induced prior under numerical validity | `34_supervisor_revision_diagnostics.py` | `induced_prior_draws.csv`, `induced_prior_summary.csv`, `supervisor_revision_metadata.json` |
| Wasserstein alpha-beta ridge | `34_supervisor_revision_diagnostics.py` | `wasserstein_ridge_summary.csv`, `figures/wasserstein_alpha_beta_ridge.png` |

The separate report figures are stored in the repository's `figures` folder.
In the original thesis workspace, script `27_export_thesis_figures.py` also
copied them to `Report/final/final figure`. Script
`33_refresh_reporting_outputs.py` refreshes the repeated-regime figures without
rerunning the expensive simulation study.
